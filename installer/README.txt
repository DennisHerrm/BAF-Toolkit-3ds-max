BAF Toolkit for 3ds Max
=======================

Imports and exports the characters of Star Wars Episode I:
The Phantom Menace (PC, 1999) - models, skeletons, textures and
animations from big.lab - in 3ds Max 2016 - 2027.

No game files are included. You need your own copy of the game.

INSTALL
  1. Close 3ds Max.
  2. Double-click Install.bat and allow the administrator prompt.
     The plugin goes to
       %ProgramData%\Autodesk\ApplicationPlugins\BafToolkit
     and is available to every user on this PC.
  3. Start 3ds Max:
       File > Import > Big Ape Actor (*.baf, *.lab)
       File > Export > Big Ape Actor (*.baf)

  If 3ds Max reports that BafToolkit.dlu could not be loaded,
  install the Microsoft Visual C++ runtime:
    https://aka.ms/vc14/vc_redist.x64.exe
  (The Setup .exe from the release page does this for you.)

UNINSTALL
  Close 3ds Max and double-click Uninstall.bat.
